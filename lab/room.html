The Room

The idea is right and the execution reads as borrowed: everywhere else this document is an old paper archive, and this one screen is clean, bright and futuristic. Four things change — the light, the core, the floor and the folders — and all four pull in the same direction, toward a room the rest of the document could actually contain.

This is a live scene, not a picture: the three things being judged only read in motion. Use the controls.

The scene

Lit like an interrogation

A single lamp above the ring, its housing cropped by the top edge so the fixture is never fully seen. A cone falls on the ring, a pool lands on the floor, and each folder takes its brightness from where it stands in the rotation — so the folder at the front is the lit one and the rotation itself becomes the lighting.

The four changes

What each one is for

The light. The current room is evenly lit, which is why it reads as a render. One cropped lamp gives the screen a direction and a source, and lets the rotation do the work — nothing needs to animate brightness, because the folder that is at the front is simply the folder in the cone.

The core: woven tube. The stack of platters on a spindle that literally WAS the core of a mainframe. It is a core in the plain sense of the word, it is unmistakably old computing, and a column of discs reads as a centre from every angle the ring turns to. Drawn the way this document draws everything: one flat matte fill, one heavy dark outline, no gradients. The memory drum beside it is the quieter option - one banded cylinder instead of a stack, more abstract and less busy.

The floor. The grid is gone entirely. This document is flat matte colour from end to end, so the floor is too: two solid planes and a skirting, no lines, nothing technical. The room stands on a surface rather than on graph paper. The old grid is one toggle away for comparison.

The folders. Classic desktop folder icons - flat fill, one heavy dark outline, a tab at the top left - in the four file colours. That is the join the current version is missing: the room stops being a render and becomes the same drawing as the rest of the document.

Before it can ship

What still has to be proven

Large soft gradients and blurs are the classic phone frame-rate killer, so the cone and pool become static on a phone and the lamp crops harder to cost no vertical room. Frame pacing gets measured in paired runs before and after, because a single run cannot tell a regression from host noise. And the horizontal track must still advance on scroll, in both directions, with all four cards readable at 360px.

Nothing here is on the site. Pick a core, say whether the light is right, and it gets built and measured.
